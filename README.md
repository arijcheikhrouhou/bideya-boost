# Bideya Boost — Plateforme d'orientation pour étudiants

**Bideya Boost** est une plateforme web interactive qui aide les élèves et étudiants tunisiens à s'orienter dans leurs études et leur carrière.

![Next.js](https://img.shields.io/badge/Next.js-React-000000) ![Tailwind](https://img.shields.io/badge/Tailwind-CSS-06B6D4)

## Fonctionnalités

- **Guide d'orientation** par domaine : ingénierie, médecine, business et éducation
- **Ateliers, conférences et hackathons**
- **Réservation de sessions d'information**, avec confirmation
- Page d'accueil avec catégories, sessions d'information et présentation

## Lancer le projet

```bash
cd bideya
npm install
npm run dev       # http://localhost:3000
```

## Technologies

Next.js (App Router) · React · Tailwind CSS · JavaScript
